This project simulates a Warehouse Management System (WMS) built using:
- C#
- ASP.NET Core
- SQL Server
- RESTful APIs
- MVC Architecture

The system will include:
- Inventory management
- Order processing
- Supplier and client tracking
- Reporting dashboard
